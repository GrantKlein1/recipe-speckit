
| Feature                                                                   | Description                                                                                                               |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| [1 — User Auth, Profile & Session Management](./feature-1-account-management.md)  | Encompasses everything around account and access management: register new user, login screen, track session, profile management. |

| [4 — Recipe Steps and Ingredients Management](./feature-4-recipe-ingredients-management.md)     | Users can add/delete/edit ingredients and steps to an existing recipe                                                                        |
| [5 — Published Recipe Management](./feature-5-published-recipe-management.md)     | Users can publish there recipe via a toggle in the edit recipe menu. Published recipes are visible to all users at the login screen via a button.                                                                        |
